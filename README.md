# Shadow Lattice Solar Sail (SLaSS) 

**Solar sails stop in shadow. SLaSS doesn't.**

A 100m² lattice sail with pixelated steering that works continuousl, light or dark. Cuts deep-space fuel by 90%.

## How It Works

**Light**: Electrochromic pixels adjust reflectance for thrust vectoring (9 μN/m²).  
**Shadow**: PCM thermal ablation sustains 10% thrust (0.9 μN/m²).  

**Result**: Earth-Mars in 1.5 years vs. stalled traditional sails.

```
F = 2(P/c)Aη = 907 μN (100m², η=0.99)
a = 90 μm/s² → Δv = 2.86 km/s per year
```

## Why Different
- **Lattice**: Perforated film (99% reflective, 30% lighter)  
- **Pixels**: Thousands of LCD panels (IKAROS scaled up)  
- **Hybrid**: PCM + magsail backup (no stalls)
